# PromptAtlas 3.0 — catálogo ampliado

Se preserva la aplicación React/Vite anterior y se añaden 458 macros de dos bibliotecas públicas.

- Fuente 1: https://github.com/Ronit049/ChatGPT-Command-Library
- Fuente 2: https://github.com/Shineii86/AISlashCommands
- Los comandos comunitarios son convenciones de prompting, **no comandos oficiales de ChatGPT**.
- Se eliminan duplicados por sintaxis exacta, manteniendo las macros personalizadas originales.
- No se incorporó la tercera biblioteca Slash-Prompt sin extraer y verificar sus entradas.
- No se ha comprobado individualmente la ejecución de cada macro.

Para publicar: subir archivos descomprimidos a la raíz del repositorio en GitHub. Vercel desplegará la rama main.

## Nuevo en v3.1

- Generador de prompt profesional extenso con contexto, público, formato, tono y restricciones.
- Vista previa y botón para copiar y abrir ChatGPT.
- Funciona localmente sin API externa.
