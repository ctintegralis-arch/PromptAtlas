# PromptAtlas 1.0

Biblioteca responsive de comandos y macros de ChatGPT, construida con React + Vite para Vercel.

## Ejecutar

```bash
npm install
npm run dev
```

## Publicar en Vercel

Sube el proyecto a GitHub, importa el repositorio en Vercel y selecciona Vite. Build: `npm run build`. Output: `dist`.

## Alcance

Catálogo inicial curado desde la conversación; no es una auditoría exhaustiva. La distinción de estado es visible. Favoritos y macros personales se guardan en `localStorage` del navegador, sin sincronización entre dispositivos. Exportación JSON para respaldo. No requiere API keys ni backend.
